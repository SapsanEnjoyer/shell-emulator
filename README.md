# Эмулятор командной оболочки (вариант 26)

Соколов Даниил, ИКБО-42-25. Дисциплина «Конфигурационное управление».

## Общее описание

Эмулятор языка оболочки UNIX-подобной ОС с графическим интерфейсом
(Python 3 + tkinter). Работа эмулятора максимально похожа на работу
в командной строке: приглашение, ввод команд, вывод результата и ошибок.

## Этап 1. REPL

- GUI-окно, заголовок содержит имя VFS: `Эмулятор оболочки - [vfs]`.
- Парсер командной строки с поддержкой кавычек (`emulator/parser.py`):
  - пробелы разделяют аргументы;
  - `'...'` — текст берётся как есть;
  - `"..."` — поддерживается экранирование `\" \\ \$ \``;
  - `\x` вне кавычек экранирует символ (`my\ dir` → `my dir`);
  - кавычки, примыкающие к тексту, склеиваются: `a"b c"d` → `ab cd`;
  - незакрытая кавычка и `\` в конце строки — синтаксическая ошибка.
- Команды-заглушки `ls`, `cd` выводят своё имя и аргументы.
- `exit [код]` — завершение работы (код должен быть числом).
- Неизвестная команда — ошибка `<имя>: команда не найдена`.

## Этап 2. Конфигурация

Параметры командной строки:

| Параметр | Описание |
|---|---|
| `--vfs PATH` | путь к физическому расположению VFS; имя файла без расширения становится именем VFS (заголовок окна, приглашение) |
| `--script PATH` | путь к стартовому скрипту эмулятора |
| `-h`, `--help` | справка |

При запуске все параметры выводятся в отладочном виде (в консоль и в окно):

```
[debug] параметры запуска:
[debug]   vfs_path    = 'vfs/demo.zip'
[debug]   vfs_name    = 'demo'
[debug]   script_path = 'scripts/startup/error.txt'
```

Стартовый скрипт — текстовый файл (UTF-8), одна команда в строке;
пустые строки и строки, начинающиеся с `#`, пропускаются. При выполнении
в окне отображаются и приглашение с вводом, и вывод, как при диалоге
с пользователем. Выполнение останавливается на первой ошибке с сообщением
`Скрипт остановлен: ошибка в строке N`. Ошибка чтения файла скрипта также
выводится в окне.

Скрипты реальной ОС для проверки параметров (`scripts/*.sh`):

| Скрипт | Что проверяет |
|---|---|
| `test_no_params.sh` | запуск без параметров |
| `test_vfs_param.sh` | только `--vfs` |
| `test_script_param.sh` | только `--script` (успешный скрипт) |
| `test_all_params.sh` | оба параметра, скрипт с ошибкой |
| `test_bad_params.sh` | несуществующий скрипт, неизвестный параметр |

Стартовые скрипты эмулятора (`scripts/startup/`): `basic.txt`,
`error.txt`, `syntax_error.txt`, `exit.txt`.

## Структура

```
src/emulator/     исходный код
  __main__.py     точка входа
  parser.py       разбор командной строки
  shell.py        ядро: выполнение команд
  config.py       параметры командной строки
  script.py       чтение стартовых скриптов
  gui.py          окно tkinter
tests/            модульные тесты (unittest)
scripts/          скрипты ОС для запуска эмулятора
scripts/startup/  стартовые скрипты эмулятора
run.sh            запуск эмулятора
Makefile          make run / make test
```

## Сборка и тесты

Сборка не требуется, нужен Python 3.9+ с tkinter.

```bash
./run.sh --vfs vfs/demo.zip --script scripts/startup/basic.txt
```

```bash
make test
```

## Примеры

```
user@vfs:/$ ls -l "my dir"
команда: ls, аргументы: ['-l', 'my dir']
user@vfs:/$ cd 'a b'\ c
команда: cd, аргументы: ['a bc']
user@vfs:/$ foo
Ошибка: foo: команда не найдена
user@vfs:/$ ls "abc
Ошибка: синтаксическая ошибка: незакрытая кавычка "
user@vfs:/$ exit abc
Ошибка: exit: abc: требуется числовой аргумент
user@vfs:/$ exit
exit
```
